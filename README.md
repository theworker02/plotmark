# plotmark

Plot and summarize mark statistics from numeric stdin samples.

**Site:** https://theworker02.github.io/plotmark/

## Install / run

```bash
git clone https://github.com/theworker02/plotmark.git
cd plotmark
node src/cli.js
node --test
```
